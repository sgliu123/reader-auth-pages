🚀 部署说明

  1. 部署后端 API：将 Cloudflare Worker 代码部署到 Cloudflare Pages/Workers，获取 API 地址
  2. 配置 CORS：确保 API 响应头包含 Access-Control-Allow-Origin: * 以支持跨域
  3. 部署管理工具：将此 HTML 文件上传到 GitHub Pages、Cloudflare Pages 或任何静态托管服务
  4. 配置 API 地址：在上方输入框填入您的 API 基础地址，点击保存
  5. 开始使用：点击「刷新统计」和「刷新列表」查看数据

💡 提示：此工具为纯前端实现，所有数据通过 API 获取。建议为 API 添加访问控制（如 API Key 或 IP 白名单）以确保安全。
